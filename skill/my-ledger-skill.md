### 2.2 参数列表

#### 记账参数

| 参数 | 类型 | 必填 | 默认值 | 描述 |
|------|------|------|--------|------|
| amount | number | 是 | - | 金额（元） |
| type | string | 是 | - | 类型：income（收入）/ expense（支出） |
| category | string | 是 | - | 分类名称 |
| date | string | 否 | 当前时间 | 日期时间，ISO 8601格式；如传入必须包含日期和时间，禁止只传 `YYYY-MM-DD` |
| note | string | 否 | null | 备注信息 |

**时间字段规则：**
- 新增或批量新增账目时，如果 AI 传 `date` 字段，必须传完整日期时间，例如 `2026-05-20T12:30:00`。
- 禁止只传日期，例如不要传 `2026-05-20`，否则会丢失真实记录时间。
- 如果用户只提供日期（如“昨天”“5月20日”）但没有提供具体时间，应使用当前时间的时分秒补齐该日期。
- 如果用户没有提供日期或时间，可以不传 `date` 字段，让系统使用当前日期时间。

#### 查询参数

| 参数 | 类型 | 必填 | 默认值 | 描述 |
|------|------|------|--------|------|
| start_date | string | 否 | 本月1号 | 开始日期 |
| end_date | string | 否 | 本月最后一天 | 结束日期 |
| type | string | 否 | 全部 | 类型筛选：income/expense |
| category | string | 否 | 全部 | 分类筛选 |
| limit | number | 否 | 100 | 返回条数 |

## 3. 输入场景与解析逻辑

### 3.1 文字输入

**场景：** 用户发送文字消息

**解析规则：**
1. 提取金额：匹配数字（支持整数和小数）
2. 提取关键词：匹配分类关键词
3. 判断类型：包含"收入/收到/到账/赚"等为收入，其余为支出

**示例：**

| 用户输入 | 解析结果 |
|----------|----------|
| 午餐25元 | amount=25, type=expense, category=餐饮, note=午餐 |
| 早餐10元 | amount=10, type=expense, category=餐饮, note=早餐 |
| 打车15 | amount=15, type=expense, category=交通, note=打车 |
| 收到红包50元 | amount=50, type=income, category=红包 |
| 工资到账8000 | amount=8000, type=income, category=工资 |
| 买衣服花了200 | amount=200, type=expense, category=服饰 |
| 充话费50 | amount=50, type=expense, category=通讯 |
| 电费150 | amount=150, type=expense, category=住房 |

**解析流程：**
```
1. 使用正则提取金额：\d+\.?\d*
2. 提取关键词进行分类匹配
3. 判断收入/支出类型
4. 组装记账参数；如包含 date，必须是完整日期时间 `YYYY-MM-DDTHH:mm:ss`
5. 调用记账API
```

### 3.2 语音输入

**场景：** 用户发送语音消息（已转文字）

**处理逻辑：**
1. 将语音转为文字（由外部ASR服务完成）
2. 按标点符号或停顿分割句子
3. 对每个句子分别解析
4. 批量调用记账API

**示例：**

| 语音转文字 | 解析结果 |
|------------|----------|
| 早餐10元午餐20 | 两笔记录：早餐10元、午餐20元 |
| 早餐10元，午餐20，收到红包50 | 三笔记录：早餐10元（支出）、午餐20元（支出）、红包50元（收入） |
| 今天打车花了15，买咖啡12 | 两笔记录：打车15元、咖啡12元 |
| 发工资了8000，交房租2000 | 两笔记录：工资8000元（收入）、房租2000元（支出） |

**解析流程：**
```
1. 接收语音转文字结果
2. 按句分割：逗号、句号、顿号、"和"、"还有"等
3. 对每句独立解析金额和分类
4. 调用批量记账接口 POST /api/ledger/batch
```

**批量记账API：**
```json
POST /api/ledger/batch
[
  {"amount": 10, "type": "expense", "category": "餐饮", "date": "2026-05-20T08:10:00", "note": "早餐"},
  {"amount": 20, "type": "expense", "category": "餐饮", "date": "2026-05-20T12:20:00", "note": "午餐"},
  {"amount": 50, "type": "income", "category": "红包", "date": "2026-05-20T19:30:00", "note": "收到红包"}
]
```

### 3.3 图片输入

**场景：** 用户发送图片（订单页面、收款页面、账单截图等）

**支持的图片类型：**

| 类型 | 特征 | 处理方式 |
|------|------|----------|
| 外卖订单 | 美团、饿了么等 | 提取订单金额、商家名称 |
| 支付成功 | 微信/支付宝支付成功页 | 提取金额、收款方 |
| 账单截图 | 银行账单、信用卡账单 | 提取交易记录 |
| 转账记录 | 微信/支付宝转账 | 提取转账金额 |
| 收款通知 | 红包、转账收款 | 提取收款金额 |
| 购物小票 | 超市、商场小票 | 提取消费明细 |

**图片解析流程：**
```
1. 接收图片
2. 调用OCR识别文字
3. 判断图片类型（订单/收款/账单）
4. 提取关键信息：
   - 金额
   - 商家/对方名称
   - 交易类型（支出/收入）
   - 交易时间（如有）
5. 自动匹配分类
6. 调用记账API
```

**分类自动匹配规则：**

| 图片特征 | 匹配分类 |

| 美团、饿了么、外卖 | 餐饮 |
| 滴滴、高德、地铁、公交 | 交通 |
| 淘宝、京东、拼多多、天猫 | 购物 |
| 微信红包、转账收款 | 红包 |
| 工资、薪资 | 工资 |
| 房租、水电、物业 | 住房 |
| 医院、药店、挂号 | 医疗 |
| 电影、游戏、KTV | 娱乐 |
| 超市、便利店 | 日用 |
| 服装、鞋帽 | 服饰 |

**示例：**

|----------|----------|

### 3.4 文件导入

**场景：** 用户发送账单文件（支付宝账单、微信账单、Excel文件等）要求导入

**支持的文件类型：**

| 文件类型 | 格式 | 来源 |
|----------|------|------|
| 支付宝账单 | CSV | 支付宝导出 |
| 微信账单 | CSV | 微信导出 |
| Excel账单 | XLS/XLSX | 自定义表格 |
| CSV文件 | CSV | 通用格式 |

#### 3.4.1 支付宝账单解析

**文件格式：**
```csv
交易时间,交易分类,交易对方,商品说明,收/支,金额,收/付款方式,交易状态,交易订单号,商家订单号,备注
2026-05-20 12:30:00,餐饮美食,美团外卖,午餐,支出,25.50,支付宝余额,交易成功,202605200001,,午餐
```

**解析规则：**
1. 跳过文件头部说明行（通常前几行为说明）
2. 解析CSV列：交易时间、交易对方、商品说明、收/支、金额
3. 收/支字段：`支出` → type=expense，`收入` → type=income
4. 根据交易对方和商品说明自动匹配分类

**字段映射：**

| 支付宝字段 | 记账字段 | 说明 |
|------------|----------|------|
| 交易时间 | date | 格式：2026-05-20 12:30:00 |
| 商品说明 | note | 交易描述 |
| 交易对方 | note | 追加到备注 |
| 收/支 | type | 支出→expense，收入→income |
| 金额 | amount | 去掉¥符号 |

**分类自动匹配：**

| 交易对方/商品关键词 | 匹配分类 |
|---------------------|----------|
| 美团、饿了么、肯德基、麦当劳 | 餐饮 |
| 滴滴、高德、地铁、公交卡 | 交通 |
| 淘宝、天猫、京东、拼多多 | 购物 |
| 转账、红包 | 红包/其他 |
| 房租、水电、物业 | 住房 |
| 医院、药店、挂号 | 医疗 |
| 话费、流量 | 通讯 |
| 超市、便利店 | 日用 |

#### 3.4.2 微信账单解析

**文件格式：**
```csv
微信支付账单明细
交易时间,交易类型,交易对方,商品,收/支,金额(元),支付方式,当前状态,交易单号,商户单号,备注
2026-05-20 12:30:00,商户消费,美团外卖,午餐,支出,¥25.50,零钱,支付成功,420000001,,午餐
```

**解析规则：**
1. 跳过第一行标题说明
2. 解析CSV列
3. 金额字段去掉¥符号
4. 根据交易类型和交易对方匹配分类

#### 3.4.3 Excel账单解析

**支持的列名格式：**

| 列名 | 对应字段 |
|------|----------|
| 日期/时间/交易时间 | date |
| 金额/金额(元)/交易金额 | amount |
| 类型/收/支/收支 | type |
| 分类/类别/交易分类 | category |
| 备注/说明/商品/描述 | note |
| 对方/交易对方/商户 | note |

**示例Excel格式：**

| 日期 | 类型 | 金额 | 分类 | 备注 |
|------|------|------|------|------|
| 2026-05-20 | 支出 | 25.5 | 餐饮 | 午餐 |
| 2026-05-20 | 收入 | 50 | 红包 | 微信红包 |
| 2026-05-19 | 支出 | 200 | 服饰 | 买衣服 |

**解析规则：**
1. 读取第一行作为列名
2. 匹配列名到对应字段
3. 逐行解析数据
4. 类型字段：支出/消费→expense，收入/到账→income
5. 分类字段如为空，根据备注关键词自动匹配

#### 3.4.4 通用CSV解析

**自动检测格式：**
1. 读取前几行，检测是否为支付宝/微信格式
2. 如果是自定义CSV，按列名匹配字段
3. 支持UTF-8和GBK编码

**文件导入流程：**
```
1. 接收文件（CSV/Excel）
2. 读取文件内容
3. 识别文件类型（支付宝/微信/通用）
4. 解析账单记录
5. 字段映射和数据清洗
6. 自动匹配分类
7. 调用批量导入API POST /api/ledger/batch
8. 返回导入结果
```

**示例：**

| 文件内容 | 解析结果 |
|----------|----------|
| 支付宝账单.csv | 解析所有交易记录，批量导入 |
| 微信账单.csv | 解析所有交易记录，批量导入 |
| 自定义账单.xlsx | 按列名匹配，批量导入 |

## 4. 功能逻辑（API）

**基础地址：** `http://localhost:8000`

### 4.1 记账操作

**接口：** `POST http://localhost:8000/api/ledger/`

**请求头：**
```
Content-Type: application/json
```

**请求体：**
```json
{
  "amount": 25.5,
  "type": "expense",
  "category": "餐饮",
  "date": "2026-05-20T12:00:00",
  "note": "午餐"
}
```

**curl示例：**
```bash
curl -X POST http://localhost:8000/api/ledger/ \
  -H "Content-Type: application/json" \
  -d '{"amount": 25.5, "type": "expense", "category": "餐饮", "date": "2026-05-20T12:00:00", "note": "午餐"}'
```

### 4.2 批量导入

**接口：** `POST http://localhost:8000/api/ledger/batch`

**请求头：**
```
Content-Type: application/json
```

**请求体：**
```json
[
  {"amount": 10, "type": "expense", "category": "餐饮", "date": "2026-05-20T08:10:00", "note": "早餐"},
  {"amount": 20, "type": "expense", "category": "餐饮", "date": "2026-05-20T12:20:00", "note": "午餐"},
  {"amount": 50, "type": "income", "category": "红包", "date": "2026-05-20T19:30:00", "note": "收到红包"}
]
```

**响应：**
```json
{"message": "成功导入 3 条记录", "count": 3}
```

**curl示例：**
```bash
curl -X POST http://localhost:8000/api/ledger/batch \
  -H "Content-Type: application/json" \

    {"amount": 10, "type": "expense", "category": "餐饮", "date": "2026-05-20T08:10:00", "note": "早餐"},
```

## 10. CLI 快捷操作（推荐）

后端提供 `backend/ledger.py` CLI 脚本，AI Agent 可直接执行命令完成记账和查询，无需手动拼接 API。

**工作目录：** `backend/`

### 10.1 记账

```bash
# 支出（默认）
python ledger.py add <金额> <分类> [备注]
python ledger.py add 25 餐饮 午餐
python ledger.py add 15 交通 地铁
python ledger.py add 200 购物 超市

# 收入
python ledger.py add 8000 工资 --type income
python ledger.py add 200 红包 --type income
python ledger.py add 500 兼职 --type income 外卖跑腿
```

**输出示例：**
```
记账成功: 支出 ¥25.0 [餐饮] - 午餐
记账成功: 收入 ¥8000.0 [工资]
```

### 10.2 查询账目

```bash
# 查询本月账目（默认）
python ledger.py list

# 查询某一天
python ledger.py list --date 2026-05-20

# 查询某月
python ledger.py list --month 2026-05

# 查询日期范围
python ledger.py list --start 2026-05-01 --end 2026-05-15

# 按类型筛选
python ledger.py list --type expense
python ledger.py list --type income

# 按分类筛选
python ledger.py list --category 餐饮

# 查询最近N条
python ledger.py list --last 10

# 组合查询
python ledger.py list --month 2026-05 --type expense --category 餐饮
```

**输出示例：**
```
共 3 条记录:
------------------------------------------------------------
  [1] 2026-05-20 12:00 支 -¥25.00 餐饮 (午餐)
  [2] 2026-05-20 08:30 支 -¥15.00 交通 (地铁)
  [3] 2026-05-19 18:00 收 +¥200.00 红包
------------------------------------------------------------
```

### 10.3 统计汇总

```bash
# 本月统计（默认）
python ledger.py summary

# 指定月份
python ledger.py summary --month 2026-05

# 指定年份
python ledger.py summary --year 2026
```

**输出示例：**
```
统计汇总:
  收入: +¥10000.00
  支出: -¥5000.00
  结余: ¥5000.00
  笔数: 50
```

### 10.4 查询分类

```bash
# 所有分类
python ledger.py categories

# 只看支出分类
python ledger.py categories --type expense

# 只看收入分类
python ledger.py categories --type income
```

### 10.5 删除记录

```bash
python ledger.py delete <id>
python ledger.py delete 1
```

### 10.6 导入支付宝账单

```bash
python import_alipay.py 支付宝交易明细.csv
python import_alipay.py 支付宝交易明细.csv --url http://localhost:8000
```

### 10.7 命令别名

支持中英文别名：

| 命令 | 别名 |
|------|------|
| add | new, 记, 记账 |
| list | ls, 查, 查询 |
| summary | 统计 |
| categories | 分类 |
| delete | del, 删除 |

```bash
python ledger.py 记 25 餐饮 午餐
```
