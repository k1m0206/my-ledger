my-ledger — 个人记账软件
1️⃣ 项目概述

项目名称：my-ledger
项目类型：个人记账软件（单体 SPA + 后端 API）
运行环境：闲置电脑本地运行
功能目标：

记录收支账目（收入/支出）
提供分类、时间筛选、统计汇总
前端 SPA 页面可视化查看账目
支持龙虾 Skill 直接调用本机接口进行记账和查询
2️⃣ 技术选型
2.1 后端
选型	原因
Python 3 + FastAPI	- 轻量、跨平台，单文件即可运行
- 快速开发 API，自动生成 Swagger 文档
- 丰富生态支持 SQLite 和前端静态文件
2.2 数据存储
选型	原因
SQLite	- 单文件数据库，无需额外服务
- 本地化、轻量化，适合单机部署
- Python 内置支持，维护简单
2.3 前端
选型	原因
SPA 前端框架（Vue3 / React）	- 前后端分离，通过 API 获取数据
- 可动态渲染表格、筛选和图表
- 可扩展功能，如导出报表、统计分析
- 提升用户可视化体验
2.4 部署方式
选型	原因
直接运行 Python 服务	- 简单易用，闲置电脑即可启动
- 无需 Docker 或 Node.js 构建环境
- 单体项目，维护成本低
2.5 龙虾 Skill 调用
选型	原因
HTTP JSON 接口	- 稳定高效，直接 POST/GET 调用后端 API
- 避免模拟鼠标/键盘的不稳定性
- 方便扩展和维护
